INSTALL

    ./install.sh --udev

That puts the app, its icon and an app-list entry under ~/.local, and
installs a udev rule so your user can open the interface without root.
Replug the interface afterwards. Without --udev only the app is installed.

Make sure ~/.local/bin is on your PATH, then start "D+ Control" from your app
list or run idctl-gui. To install somewhere else: PREFIX=/usr/local ./install.sh

REQUIREMENTS

  * 64-bit Linux (x86_64) with glibc 2.35 or newer (Ubuntu 22.04, Debian 12
    and later, Fedora, Arch and similar).
  * libusb-1.0 and libudev. On Debian and Ubuntu: sudo apt install libusb-1.0-0
    On Fedora: sudo dnf install libusb1   On Arch: sudo pacman -S libusb
  * A desktop with Wayland or X11 and working OpenGL or Vulkan.
  * PipeWire with its command-line tools (pw-top, pw-dump, pw-cli,
    pw-metadata) and stdbuf from coreutils, for the Latency page and for
    changing the sample rate. The rest works without PipeWire.

If it does not start on your system, build it from source instead; the
steps are in the README: https://github.com/Kerf-Audio/idctl

UNINSTALL

    ./uninstall.sh --udev
